# EXIF Hound — Product Context

## What it is
A free, **open-source** desktop application for EXIF / image metadata analysis. Built with Tauri (Rust) + React. Cross-platform: Windows, macOS, Linux.

## Key facts (from legacy site, verified)
- Examines image metadata **locally** — nothing uploaded to external servers.
- Identifies hidden metadata: geolocation, camera settings, timestamps.
- Batch processing: analyze multiple images simultaneously.
- Privacy protection: identify and remove sensitive personal information.
- Detailed reporting; intuitive for beginners and experts.

## Positioning (changed)
- **One version.** No Community/Pro split. No pricing, no "Buy Now", no Stripe/licensing.
- **Open source project.** Repo: https://github.com/minimallyexceptional/exif-hound
- CTAs: Download (→ GitHub releases) and View on GitHub. No accounts, no subscriptions.
- No license/checkout/support-portal pages exist anymore.
